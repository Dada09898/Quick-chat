# DualConnect

A highly secure, zero-trust, browser-based private communication platform exclusively for TWO users.

## Features
- E2EE Messaging, Media, and Voice/Video calls.
- Encrypted Vault.
- Strict 2-user architecture with Argon2 and WebAuthn.
- Responsive, Glassmorphism UI built with React 19, Tailwind, and Framer Motion.

## Setup Development
1. Ensure Docker and Docker Compose are installed.
2. Run \`make up\` to start the development environment.
3. Access Frontend at http://localhost:5173
4. Access Backend at http://localhost:8000
